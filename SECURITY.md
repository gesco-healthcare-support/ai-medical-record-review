# Security policy

## Supported version

Only the code on the `production` branch is supported. A fix is made on `main` and reaches
`production` through the promotion order described in [CONTRIBUTING.md](CONTRIBUTING.md).

## Reporting a vulnerability

Report a vulnerability privately, through this repository's **Security** tab: choose
**Report a vulnerability**. That opens a private security advisory that only the maintainers and
you can see; the fix and any disclosure are coordinated there.

- Do not open a public issue, pull request or discussion about a vulnerability.
- Do not include patient data or any real personal information. This application processes
  medical records; describe the problem with synthetic examples only.
- Say what is affected (file, route, setting or workflow), how to reproduce it, and the impact you
  expect.
