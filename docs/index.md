# MRR AI documentation

MRR AI (AI Medical Record Review) turns a large scanned medical-record PDF into a reviewed,
summarized Medical Record Review. A reviewer corrects the machine's work at every stage: the app is
an assistant, not an autopilot.

This site is built from the Markdown files in the repository's `docs/` folder with
Material for MkDocs. The pages follow the [Diataxis](https://diataxis.fr/) split:

- **Tutorials** - learn by doing, start to finish.
- **How-to guides** - carry out one task you already understand.
- **Reference** - look up exact facts: routes, settings, tables, states.
- **Explanation** - understand how a part works and why it is built that way.
