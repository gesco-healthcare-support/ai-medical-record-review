# frontend/components/ui

Primitives shared by every screen: shadcn/ui wrappers over Radix (generated by the shadcn CLI from
`frontend/components.json`, style `radix-nova`), the toaster, the tooltip provider, and one custom
control, `SegmentedTabs`. Their colours come from the shadcn semantic slots that
`frontend/app/globals.css` maps onto the Evaluators tokens.

| File | What it is |
| --- | --- |
| `button.tsx` | `Button`, `buttonVariants`: the shadcn button with `cva` variants. Used inside `dialog.tsx` and `alert-dialog.tsx` only; app buttons use the `ev-btn` classes |
| `dialog.tsx` | `Dialog` and its parts (`DialogContent`, `DialogHeader`, `DialogFooter`, `DialogTitle`, `DialogDescription`, `DialogOverlay`, `DialogPortal`). Used by the export, category, prompt and split-upload dialogs |
| `alert-dialog.tsx` | `AlertDialog` and its parts, including `AlertDialogAction` and `AlertDialogCancel`. Used by `ConfirmDialog` on My documents |
| `dropdown-menu.tsx` | `DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuLabel`, `DropdownMenuItem`, `DropdownMenuSeparator`. Used by the user menu and the My documents row menu |
| `segmented-tabs.tsx` | `SegmentedTabs`: a controlled pill switch (`role="tablist"`, buttons with `role="tab"` and `aria-selected`). Workbench tabs and bundle tabs |
| `sonner.tsx` | `Toaster`: sonner, light theme, 3500 ms, navy surface, lucide icons. Placed by the root layout |
| `tooltip.tsx` | `TooltipProvider` only. Hover hints in the app are native `title` attributes |

None of these files has its own test; they are exercised through the components that use them.

## Use, run and test

Import with the alias, for example `import { Dialog, DialogContent } from "@/components/ui/dialog"`.
Add a new primitive with the shadcn CLI from `frontend/`:

```bash
cd frontend
pnpm exec shadcn add popover
```

Then run the tests of the components that use it.
